# 탐지 & 대응

> 예방이 뚫렸을 때를 전제로 **빠르게 발견하고 대응**하는 영역입니다. NIST CSF의 *Detect · Respond* 에 해당합니다.

## 이 영역으로 해결하는 것
- 위협·이상 징후의 **상시 탐지**와 **중앙 로깅·감사**
- 인시던트 **대응 체계**와 포렌식·자동화
- 탐지 공백(coverage gap)의 가시화
